# バージョンの棚（体験版）

ソフトの版（バージョン）を、CDの棚のように並べて見せる画面の**体験版**です。棚を送って1枚を開くと、その版のリリースノートが読めます。

**体験版（ブラウザで開けます）**：https://updating30.github.io/version-shelf-demo/

## 解決したいこと

| よくある困りごと | この画面では |
|---|---|
| 更新履歴が長い文字の一覧になっていて、読む気になれない | 版を1枚ずつの「盤」にして棚に並べ、送りながら眺められる |
| いまどの版を見ているのか、全体のどこなのかが分からない | 下の目盛りと「31 / 36」で、全部のうちの何番目かがいつも見える |
| 大きな更新と小さな修正の区別がつきにくい | 大きな更新ごとに表紙の色の系統が変わり、版の題の下に「大きな更新／小さな更新／不具合の修正」が出る |
| 最新の版にすぐ戻れない | 「最新へ」を押すと、棚が流れていちばん新しい版で止まる |

## 体験版について

- 架空のメモアプリ「Sample Notes」の版が36個（v1.0.0〜v3.5.0）、古い順に左から並んでいます。ソフトも版の中身もすべて架空です
- 表紙の絵は、版の番号と色から自動で作っています。背景は、今の版の表紙の色に変わります
- データはページの中にあり、どこにも送信しません

## 試してほしい流れ

1. **棚を送る**：PCはホイールかドラッグ、スマホは指で横に送る。今の1枚が手前に引き出され、上の題と背景の色が変わる
2. **一気に移る**：下の目盛りをなぞる・押す。←→キーでも1枚ずつ動く。背表紙を押すと、その版が中央に来る
3. **最新へ**：「最新へ」を押すと、棚が勢いよく流れて v3.5.0 で止まる
4. **開く**：中央の1枚を押す（または Enter）と、ふたが開いてリリースノートが出る。「棚に戻る」か Esc で戻る

## 作りの特徴

- 棚は CSS の3D変形だけで組み、ライブラリを使わない1枚のHTMLです
- 送っている途中でも、前後のケースがぶつからない・重ならないように、位置の計算を画面の処理から分けた関数にし、すべての位置で重なりが無いことを確かめています
- 止まる時はばねのように少し行き過ぎて戻ります。端末の「動きを減らす」設定では、ばね・回転を止めて切り替えるだけにします
- どの版の色の上でも、文字が読める濃さ（コントラスト 4.5:1 以上）を保っています
